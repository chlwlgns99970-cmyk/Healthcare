# 기본 과일·채소 데이터 출처

앱의 기본 음식 검색에서 생과일·생채소가 누락되지 않도록, 미국 농무부(USDA)
FoodData Central의 **SR Legacy (2018-04) CSV**에서 아래 항목을 발췌했다.

- 원문 안내: https://fdc.nal.usda.gov/download-datasets/
- 원문 CSV: https://fdc.nal.usda.gov/fdc-datasets/FoodData_Central_sr_legacy_food_csv_2018-04.zip
- 기준: 100 g
- 사용 영양소: Energy (kcal), Carbohydrate, Protein, Total lipid (fat), Sodium

수치는 공식 CSV 값을 100 g 기준 그대로 옮겼으며, 비슷한 음식의 수치를 복사하거나
칼로리·탄단지·g/ml 값을 추정하지 않았다. 완성 샐러드와 드레싱 포함 제품은 이 기본
생채소 항목과 합치지 않고 기존 원본 데이터의 별도 음식으로 유지한다.
