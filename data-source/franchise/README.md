# 프랜차이즈 영양정보 출처

앱의 기록 가능한 프랜차이즈 메뉴는 별도의 추정 데이터나 런타임 API를 사용하지 않습니다.
기존 로컬 번들 `app/src/main/assets/fooddata/food_items.csv`에서 식품의약품안전처
K-FIND 음식 DB의 업체명이 아래 프랜차이즈와 정확히 일치하는 행만 분리해 보여줍니다.

- 출처: 식품의약품안전처 식품영양성분 데이터베이스(K-FIND / K-FCDB)
- 공식 URL: https://various.foodsafetykorea.go.kr/nutrient/
- 로컬 데이터 기준일: 2026-08-28
- 확인일: 2026-09-26
- 저장 방식: 기존 `FoodItem` 및 `food_items.csv` 재사용(새 Room 열 없음)
- 단위 정책: 원본의 `100g`/`100ml` 등 기준을 그대로 보존하고 g↔ml 변환 금지
- 미제공 영양소: `null` 유지, 임의 계산 금지

## 이번 번들에서 제외한 조사 대상

아래 브랜드는 현재 로컬 K-FIND 음식 DB에서 업체명이 정확히 일치하는 행이 0개이므로
영양값을 추정하거나 다른 메뉴를 대신 넣지 않았습니다.

- 메가MGC커피
- BBQ
- 네네치킨

공식 제공량과 열량을 같은 기준으로 검증할 수 없는 세트 메뉴도 별도 합산하지 않습니다.
향후 데이터 갱신 시에도 공식 DB 행과 원본 단위를 그대로 가져오는 경우에만 포함합니다.

## 공식 브랜드 탐색 레지스트리

2026-09-27부터 공식 사이트에서 운영을 확인한 브랜드는 영양정보 유무와 별개로 카테고리 탐색에
노출한다. 공식 영양 수치가 없는 브랜드는 메뉴 수 0개와 `영양정보 미확인`으로 표시하며,
기록 가능한 `FoodItem`이나 가짜 영양값을 생성하지 않는다. 실제 목록·공식 URL·별칭은
`app/src/main/java/com/example/healthcare/domain/FranchiseCatalog.kt`가 단일 기준이다.

- 기존 19개 브랜드 및 2,440개 공식 메뉴 유지
- 전체 탐색 브랜드 57개
- 추가 카테고리: 찜닭, 국밥, 분식, 김밥, 중식, 마라탕, 죽, 국수·우동, 돈가스,
  족발·보쌈, 부대찌개, 도시락, 덮밥, 샤브샤브, 샐러드·포케, 샌드위치, 토스트
- 일반 검색에서도 카테고리·브랜드·별칭을 함께 검색

## 브랜드별 전수 감사

57개 브랜드의 카테고리, 공식명, 별칭, 공식 URL, 확인일, 기록 가능한 메뉴 수,
kcal 제공 수, 탄단지 완전 수, 공식 메뉴명 참고 수, 런타임 자동 업데이트 지원 여부와
snapshot-only 이유는 [`brand-audit.csv`](brand-audit.csv)에 기록한다. 이 파일은
`tools/generate_franchise_brand_audit.ps1`가 실제 Kotlin 레지스트리와 두 번들 CSV를 읽어
생성하므로 문서 수치와 앱 데이터가 어긋나지 않는다.

공식 메뉴명만 확인되고 영양 기준량·열량이 확인되지 않은 메뉴는 검색 참고 항목으로만
표시하며 기록 가능한 `FoodItem`을 만들지 않는다. 현재 해당 참고 항목은 백소정 5개,
한솥 3개, 이삭토스트 5개, 캠토토스트 2개다.
